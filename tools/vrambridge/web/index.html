Run settings

Automatic chooses the optimized profile only for a supported model and installed backend. Other models use standard execution.

Automatic uses llama.cpp fitting with a 1 GiB GPU margin. It is not a RAM-fit guarantee. Larger contexts need more memory.

Advanced performance (experimental)

Official backend only. Raising the batch threshold can avoid weight-transfer overhead for short prompts while retaining GPU offload for large batches. It does not relocate already-resident GPU weights.

Fewer threads can be faster. RAM loading can increase memory pressure. The upstream experimental expert cache uses VRAM, requires a supported MoE backend, and may be slower. Zero disables it.

DFlash needs a compatible, target-trained draft, automatic placement, and no explicit expert cache. For the tested 0.8B draft, start with a 4,096 MiB reserve. This is experimental; fit and speed are not guaranteed.
